# Use Pebble Protocol packets as the HAL companion seam

`runtime/core/` exchanges companion traffic across `pebble_hal_t` as standard 4-byte-framed Pebble Protocol packets (`[uint16_be length][uint16_be endpoint][payload]`, starting with `0x0030` `AppMessage` and `0x0034` `AppRunState`) via generic `send_protocol_packet` / `recv_protocol_packet` hooks rather than bespoke `AppMessage` C structs or JSON bridges. Speaking authentic Pebble wire frames inside the core adds negligible framing code on top of `Dictionary` serialization while letting the built-in desktop `PebbleKit JS Companion`, external Pebble CLI tools (`--pebble-port`), custom `brilliant_sdk` BLE tunnels, and a future BLE Reversed PPoGATT watch persona attach to the exact same runtime seam without modifying `runtime/core/`.
